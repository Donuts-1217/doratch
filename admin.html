容量 (MB) 與作品數為雙重限制，兩者皆不可超過。容量只影響「未個別設定 cloudStorageLimitMB」的使用者；若調降後導致超量，系統會給原本未超量者 1 個月寬限期。

超過上限時，系統會自動刪除最舊訊息（私訊、群組、伺服器皆適用）。預設 300 則。

免費方案（推薦）：複製專案內 scripts/python-tutor-gas-proxy.gs 到 Google Apps Script， 在「指令碼屬性」設定 GEMINI_API_KEY 與 ALLOWED_ORIGIN（你的 GitHub Pages 網域）， 部署為「網頁應用程式（任何人）」→ 把 /exec URL 貼到上方。不需 Firebase Blaze。

免費 tier 建議使用 gemini-2.5-flash-lite；舊版 2.0 / 1.5 模型已下架，若 admin 仍存舊名稱 GAS 會自動對應。若出現配額錯誤，請至 Google AI Studio 查看用量，並重新部署最新版 GAS 代理（會自動嘗試備援模型）。

未啟用時使用離線規則助教（完全免費）。Firebase 後端需 firebase deploy --only functions:pythonTutorGemini。
